# wedding

**[→ 문서 열기](https://haliacoast-sys.github.io/wedding/)**

## 내용

| 파일 | 설명 |
|---|---|
| `index.html` | 표지 · D-day |
| `saju.html` | 사주 종합 분석 (8탭) — 명식 · 신살 · 진로/재물 · 궁합 · 택일 · 주거 · 자녀 |
| `wedding.html` | 홀 계약 정리 (7탭) — 계약 내용 · 비용 · 시간 변경 · 확인 사항 · 일정 |

## 예식

- **2027년 9월 4일(토) 12:30**
- CA웨딩컨벤션 2F 루체홀 (충남 아산시 배방읍 희망로 100)
- 보증인원 200명

## tools/

절기와 음력을 외부 라이브러리 없이 직접 계산합니다.

| 파일 | 역할 |
|---|---|
| `astro.py` | VSOP87 절단급수 기반 태양황경, Meeus ch.49 삭(朔) 계산 |
| `core.py` | 60갑자, 사주 4주 산출, 절기 기반 월건, 대운 |
| `analyze.py` | 십성 · 12운성 · 공망 · 오행 분포 · 대운 전개 |
| `taegil.py` | 2027년 택일 엔진 (가취월 · 건제12신 · 황도12신 · 귀인 · 용신) |
| `taegil2.py` | 2027 하반기~2028 주말 택일 (공휴일 · 연휴 · 샌드위치 자동 배제) |

정확도 검증: 2024년 동지 12/21 18:20 KST, 2025년 춘분 3/20 18:01 KST — 공표값과 일치.

```bash
python3 tools/analyze.py     # 명식·대운 출력
python3 tools/taegil2.py     # 주말 택일 순위
```
